# Simple Calculator Application

An interactive calculator application developed for the **Learning Manual Testing** course activity at **The Open University of Sri Lanka (OUSL)**.

**GitHub Repository:** [https://github.com/numair-it/simple-calculator](https://github.com/numair-it/simple-calculator)  
**Author:** numair-it  
**Current Version:** v1.0.0 (Initial Release)

---

## Overview
This repository contains a simple calculator application implemented in Python, along with manual test case scenarios, defect reporting, and version control upgrades as part of the manual testing lifecycle.

### Features in v1.0.0:
- **Addition (`+`)**: Adds two numbers
- **Subtraction (`-`)**: Subtracts second number from first
- **Multiplication (`*`)**: Multiplies two numbers
- **Division (`/`)**: Divides first number by second
- **Modulus (`%`)**: Computes remainder of division
- **Power (`^`)**: Raises base to exponent
- **Square Root (`sqrt`)**: Computes square root of a number

---

## How to Run the Calculator
Ensure you have Python 3 installed on your system.

```bash
python calculator.py
```

Follow the on-screen menu prompts to choose an operation and input numbers.
